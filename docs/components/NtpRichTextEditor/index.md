# NtpRichTextEditor

Markdown editor for rich text content. Built on Milkdown. Supports raw LaTeX input. Figure attachment features deferred to V2.

## Components

| Component | Public | Purpose |
|---|---|---|
| `NtpRichTextEditor` | ✅ | Markdown editor with default toolbar |
| `NtpRichTextEditorToolbar` | ❌ Internal | Default toolbar |
